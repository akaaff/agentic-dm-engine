# agentic-dm-engine

A local-model AI Dungeon Master for D&D 5e: a deterministic rules engine (dice, HP, turn order, movement, conditions - zero LLM), LangGraph orchestration for intent-parsing/narration/companion-agents/judging, a LoRA-distilled small local model for intent parsing, and local image generation for per-round scene art - all served through a playable React web app.

Status: early build (see `CLAUDE.md` for the engineering log and `DECISIONS.md` for architecture rationale). Not yet playable end-to-end.
